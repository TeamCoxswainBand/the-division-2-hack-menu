## 🧩 About

**The Division 2 Companion** is a curated list of The Division 2 open-source tools:

- **Overlays** — on-screen helpers, layout notes, overlay viewer, loot tracker
- **Quality-of-Life Helpers** — gear catalog, loadout manager, overlay notes
- **Research Notes** — mission layouts and config notes for educational use

Based on publicly available community tools and overlay helpers.

---

## ✨ Features

### 🎮 Combat Helpers
- overlay Overlay — visualize enemy positions
- Loot Tracker — highlight loot containers
- Replay Notes — record and review encounters
- Playback Speed — adjust replay speed for study (0.1x to 5x)

### 🎨 Catalog & Cosmetics
- Gear Catalog — browse weapons, armor, mods
- Custom Loadout Notes — organize builds
- HUD Enhancements — improved visibility

### 🏋️ Practice Layout
- Mission Mode Notes — segment study on any mission
- Movement Control — manually adjust player position mid-mission
- Quick Swap Notes — chain complex maneuvers in the field
